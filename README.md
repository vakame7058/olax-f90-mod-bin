# OLAX F90: мод и готовая панель

Чужие файлы для установки [olax-f90-mod](https://github.com/vakame7058/olax-f90-mod): мод danya.postfactum и готовая сборка панели, в которую входит веб-часть этого мода. Исходники, инструкции и наш код — в основном репозитории. Файлы лежат в [релизе](https://github.com/vakame7058/olax-f90-mod-bin/releases/latest), контрольные суммы — в [SHA256SUMS](SHA256SUMS).

> Внимание: проверено только на прошивке `F90_P42U17_18`. Все на свой риск.

## Файлы

| файл | что это | откуда | где нужен |
|---|---|---|---|
| `olaxf90-mod-19.02.2026.zip` | мод F90: веб-часть, `goahead`, `zte_mifi`, скрипты установки | danya.postfactum, тема OLAX F90 на 4PDA | основа панели: `web/build.sh` берет из него `web.zip` |
| `olax-f90-web.tar.gz` | готовая панель: веб-часть мода с нашими файлами и правками | `web/build.sh` из основного репозитория | вместо сборки: распакуйте в каталог и передайте его `install.sh` |

Архив мода выложен без изменений. Из мода для панели нужна только веб-часть: `goahead` и `zte_mifi` мода наша установка не ставит, на свистке остаются стоковые.

## Проверка

```bash
sha256sum -c SHA256SUMS
```

## Установка

[Установка](https://github.com/vakame7058/olax-f90-mod/blob/main/docs/install.md) в основном репозитории. С готовой панелью шаг сборки заменяется распаковкой:

```bash
mkdir -p build/web && tar -xzf olax-f90-web.tar.gz -C build/web
./install.sh build/web
```

## Права

Мод и его веб-часть принадлежат danya.postfactum, исходная веб-панель — производителю. Здесь они собраны для удобства владельцев свистка. Если вы правообладатель и хотите убрать файл, откройте issue.
